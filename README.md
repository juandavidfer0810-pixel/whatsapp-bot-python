# whatsapp-bot-python
# Bot de WhatsApp con Python y Flask

Bot conversacional con menú interactivo desarrollado para gestión 
de clientes, construido con Python y Flask integrado con la API 
de WhatsApp Business.

## Funcionalidades
- Menú principal interactivo por número
- Submenús de información y catálogo de productos
- Gestión de estado por usuario (conversaciones independientes)
- Respuesta automática con derivación a asesor humano

## Tecnologías usadas
- Python 3
- Flask (servidor web)
- API de WhatsApp Business (Webhooks)
